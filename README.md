# 运动打卡小程序

一个简洁好看的微信小程序，支持多人不同地方网络打卡，直观展示30天打卡动态。

## 功能特点

- **每日打卡**：只能打当天的卡，每人每天限一次
- **微信授权**：获取用户头像和昵称，打卡记录显示真实身份
- **12种运动预设**：爬山、健身房、跑步、骑行、游泳、瑜伽等
- **自定义内容**：可自由填写运动详情，如"引体向上20个×3组"
- **30天日历视图**：直观展示过去30天每天有谁打了卡（头像显示）
- **云端存储**：数据保存在微信云开发数据库，多人多设备实时同步

## 页面结构

```
pages/
├── index/       # 今日打卡页（首页）
├── checkin/     # 打卡填写页
└── history/     # 30天打卡动态页
```

## 快速开始

### 第一步：开通云开发环境

1. 登录 [微信公众平台](https://mp.weixin.qq.com)，左侧菜单找到「云开发」，点击开通（免费）
2. 打开微信开发者工具，顶部点「云开发」按钮，创建一个环境，记下**环境 ID**（格式类似 `xxx-xxx-abc123`）

### 第二步：配置环境 ID

打开 `app.js`，找到第 8 行，把环境 ID 填进去：

```js
wx.cloud.init({
  env: '你的环境ID',   // ← 改这里
  traceUser: false,
});
```

### 第三步：创建数据库集合

在云开发控制台 → 数据库 → 新建集合，名称填：

```
checkins
```

权限设置选「所有用户可读，仅创建者可写」（默认即可）。

### 第四步：配置 appid 并运行

在 `project.config.json` 中填入你的 `appid`，然后在微信开发者工具中编译运行。

## tabBar 图标

`app.json` 的 tabBar 未配置图标，可从 [iconfont](https://www.iconfont.cn/) 下载免费图标放入 `assets/icons/`，
或保持现状（微信允许无图标 tabBar）。

## 注意事项

- 云开发免费额度：每天 1000 次数据库读写、5GB 存储，家庭/小团队完全够用
- 用户身份（头像、昵称）存在本地，换设备需重新设置
- 小程序码需要正式发布后才能分享给他人
